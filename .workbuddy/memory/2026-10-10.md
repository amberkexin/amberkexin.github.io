## 个人主页模板 + GitHub Pages 自动化部署

**产出文件**（工作区根目录）：
- `index.html` — 纯静态个人主页模板（Hero / 关于 / 技能 / 项目卡片 / 联系 / 页脚），零依赖零构建
- `style.css` — 样式，`:root` 变量集中管理配色，支持浅色/深色双主题（右上角切换，默认跟随系统）
- `deploy.sh` — 交互式一键部署脚本：建远程仓库 → 提交 → push → 开启 Pages → 打印网址
- `README.md` — 使用与部署说明
- `.gitignore`

**技术决策**：
- 网页用原生 HTML+CSS+少量 JS，不用框架，理由：GitHub Pages 直接托管，用户自己改起来门槛低
- 部署认证方式：用户选择「自己执行、token 不经过 AI」。因此做成 `deploy.sh` 交互式脚本，
  token 用 `read -s` 隐藏输入，仅作为一次性 push URL 使用，push 完 `git remote set-url` 恢复干净地址，
  不落盘到 `.git/config`
- 远程仓库创建、Pages 开启均走 GitHub REST API（`POST /user/repos`、`PUT /repos/{o}/{r}/pages`）
